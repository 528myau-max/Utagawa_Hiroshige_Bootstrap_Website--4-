Project Overview
Utagawa Hiroshige (Designer)
I used a light tan color theme with lots of his pictures incorporated around the website. (style)
Design Decisions
I separated the elements of design from the principles of design.
I used a tan color theme with a paintbrush-like font and a plain background texture, like the elements I pointed out in his artworks. (Elements)
I used lots of white space around to emphasize the main focus of the descriptions and images. Each section was usually balanced between images and descriptions. I repeated some of the same formats. (Principles)
Mobile Design
I made sure it was responsive to different-sized screens, made hovers, and clearer buttons in enhance the mobile experience.
Ai Assistance
ChatGPT gave me the basis of the website after I sent the Canva file and photos.
Copilot helped me figure out some code issues and helped me incorporate different styles.
Ai Prompt
ChatGPT prompt is attached to the assignment as a screenshot PNG, which gave me a downloadable file to set up the website.
Copilot prompts were suggestions such as "create a hover for the pictures" or "use a font that's paintbrush-like," which then incorporated my ideas into the website. 
Revisions
After seeing the website for the first time after ChatGPT gave me the basis, I had to add changes such as format changes, images, fonts, buttons, and more.
